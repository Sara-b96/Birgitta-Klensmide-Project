# Birgitta Klensmide

A website project developed as part of my examination work during my
Webmaster studies at University West.

The main purpose of the project was to work with search engine
optimization (SEO) and improve the website's visibility, structure
and user experience.

## About the project

The project involved developing and optimizing a website for
Birgitta Klensmide.

My work included both the technical structure of the website and
SEO-related improvements, with a focus on creating a clear,
accessible and user-friendly website.

## Technologies used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Search Engine Optimization (SEO)

## Areas of focus

- Technical SEO
- On-page SEO
- Website structure
- Content optimization
- Responsive design
- Navigation and usability
- Image optimization
- Sitemap
